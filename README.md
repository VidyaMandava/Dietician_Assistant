# AI-Powered Dietician Assistant

An intelligent nutrition planning assistant that generates customized meal plans and provides nutritional information based on Indian cuisine.

## Features

- **Toddler Meal Plans**: Generate a complete 7-day diet plan for 4-year-old children with appropriate portion sizes and nutritional information.
- **Adult Weight Loss Plans**: Create a detailed 7-day weight loss diet plan for adults with calorie counts and macronutrient distribution.
- **Recipe Nutrition**: Get detailed nutritional information for specific recipes, including calories, proteins, carbohydrates, and essential vitamins.
- **Recipe Instructions**: Generate comprehensive preparation instructions for various dishes, including ingredients, cooking steps, and dietary modifications.
- **Request History**: View and keep track of your previous requests and meal plans.

## How to Use

1. Select the tab for the function you want to use
2. For meal plans, click the generate button
3. For nutrition info or recipes, enter the dish name and click the corresponding button
4. View your request history in the History tab

## About

This application uses a Retrieval-Augmented Generation (RAG) system built with LangChain and OpenAI to provide nutrition and diet advice. The system is trained on a collection of Indian cuisine documents and combines this knowledge with general nutrition expertise.

Created with ❤️ using LangChain, OpenAI, and Gradio.
